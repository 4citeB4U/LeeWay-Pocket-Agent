# LeeWay Pocket Agent

Voice-first Android Agent Lee for Samsung Galaxy.

## Core goals
- Black canvas + animated 3D voxel sphere UI
- Agent Lee Hip-Hop/OG persona
- Natural cloned neural voice
- Barge-in / interruption support
- Web research
- Camera vision
- Calendar, reminders, calls, contacts
- Dual long-term memory: Personal Memory + Lee's Notebook
- BitNet/local intelligence where viable, online fallback when useful
- GitHub Actions APK builds

Target artifact: `LeeWay-Pocket-Agent.apk`
