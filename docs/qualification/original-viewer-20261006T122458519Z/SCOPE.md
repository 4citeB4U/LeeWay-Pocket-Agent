## Implemented and built

The Agent Lee sphere's existing hamburger Digital Brain control now opens an internal, non-exported DigitalBrainActivity rather than replacing the sphere document with JSON. The activity contains the recovered original Galaxy renderer, adapted to bounded read-only queries against this installation's existing Brain database. No second APK, launcher, Brain database, identity, runtime, conversation engine or voice binding was introduced.

The portable BrainViewer contract and AndroidBrainViewer adapter expose root, direct children, node/ancestors, recorded relationships/provenance and bounded search. The same existing nodes/edges/provenance tables are used. Child membership follows parent records, not relationship neighbors. Search computes the selected object's actual sibling page. Tombstoned nodes, wrong owners, foreign-body IDs, inconsistent pages and missing sources fail visibly.

The native WebView accepts only its fixed internal asset origin and explicit packaged assets. It does not allow arbitrary file/content URLs, remote navigation or execution commands. The original code that fetches full file content is not used; this viewer is metadata/evidence read-only. It does not pause global WebView timers or replace the selected LeeWay Voice.
