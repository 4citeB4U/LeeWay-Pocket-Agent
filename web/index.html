LeeWay Pocket Agent

Agent Lee in your pocket. Voice-first Android build.

Download LeeWay Pocket Agent

Android may ask you to allow installs from your browser or Files app. The APK is built directly from this repository by GitHub Actions.

Install on Samsung Galaxy
  1. Tap the download button.
  2. Open the downloaded APK.
  3. If prompted, allow “Install unknown apps” for your browser or Files.
  4. Tap Install, then Open.
  5. Grant microphone, camera, contacts, and calendar permissions when Lee asks.
